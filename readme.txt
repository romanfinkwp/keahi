== Description ==

Keahi is a free, lightweight WordPress block theme for personal websites, portfolios, and business landing pages. Built for the Site Editor with Full Site Editing support, it works out of the box for freelancers, designers, developers, photographers, consultants, coaches, and any professional who needs a clean online presence.

The theme ships with 5 ready-made block patterns: hero section, services overview, portfolio case studies grid, about page, and a full-width footer with social links. Every element is customizable through the WordPress Site Editor — no coding required.

**Key features:**

* Warm cream background with bold red accents and sharp typography
* Fully responsive design optimized for mobile, tablet, and desktop
* 5 starter patterns for one-page portfolio or multi-page business site
* Custom block styles: text balance wrap and mobile column reverse
* Sticky footer that stays at the bottom on short pages
* Fast and minimal — no JavaScript, no frameworks, no dependencies
* SEO-friendly semantic HTML with proper heading hierarchy
* GPLv2 licensed, free forever

== Installation ==

1. In your WordPress admin panel, go to Appearance > Themes and click "Add New".
2. Click "Upload Theme" and choose the keahi.zip file.
3. Click "Install Now" and then "Activate".
4. Go to Settings > General and set your site title to your desired name.
5. Navigate to Appearance > Editor to customize the theme using the Site Editor.
